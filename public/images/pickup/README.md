# ピックアップ買取 画像フォルダ

買取表の「ピックアップ買取」に出す画像は、このフォルダに保存してください。

## 使い方

1. 画像ファイルをこのフォルダ(`public/images/pickup/`)に保存する
   (ファイル名の例: `pickup-01.jpg`)
2. 買取表スプレッドシートの該当行の `image_url` 列に、次の形式で入力する

   ```
   /images/pickup/pickup-01.jpg
   ```

3. 同じ行の `pickup` 列を `TRUE` にする

これでサイトの「ピックアップ買取」に自動で表示されます(最大4枚まで)。

imgurなどの外部リンクを使う場合は、このフォルダを使わなくても大丈夫です。

# スプレッドシートの作り方

このフォルダの3つのCSVファイルを、Googleスプレッドシートに読み込んで使います。

## 手順

1. [Googleスプレッドシート](https://sheets.google.com)で新しいスプレッドシートを作成する
2. シート下部のタブを3つ用意し、名前を「買取表」「在庫」「買取実績」など分かりやすい名前に変更する
3. 各タブに、対応するCSVファイルの中身をコピー&ペーストする(またはファイル > インポート でCSVを取り込む)
   - `kaitorihyo.csv` → 買取表タブ
   - `zaiko.csv` → 在庫タブ
   - `jisseki.csv` → 買取実績タブ
4. 1行目(見出し行)は消さずに残す。2行目以降のサンプル行は、実際の商品データに書き換える(行を増やせば商品を追加できる)
5. 各タブごとに、**ファイル → 共有 → ウェブに公開** を選び、対象を「シート1(買取表)」のように該当タブに限定し、形式を「カンマ区切りの値(.csv)」にして公開する
6. 表示されたURLをコピーし、`src/data/sheet-config.js` の該当箇所に貼り付ける
   - 買取表タブのURL → `KAITORIHYO_CSV_URL`
   - 在庫タブのURL → `ZAIKO_CSV_URL`
   - 買取実績タブのURL → `JISSEKI_CSV_URL`

## 列の意味

### 買取表タブ(kaitorihyo.csv)

| 列名 | 内容 | 例 |
|---|---|---|
| category | ジャンル。`pokemon` / `yugioh` / `onepiece` のいずれか | pokemon |
| card_name | カード名検索で使われる商品名 | リザードン |
| image_url | 商品写真のURL。空欄でも可(プレースホルダー表示になる) | (空欄でOK) |
| condition | 一覧に表示される状態・鑑定情報の文言 | PSA10 鑑定品(初期エラー版) |
| price | 表示する価格 | ¥98,000 |
| diff | 前回比。空欄でも可 | ▲2,000 |
| graded | 鑑定品なら `true`、それ以外は `false`(`TRUE`/`FALSE`でも可) | true |
| grade_label | gradedがtrueのときのラベル | GRADED・10 |
| highlight | 「注目の高額買取」にも出すなら `true`(`TRUE`でも可) | true |

### 在庫タブ(zaiko.csv)

| 列名 | 内容 | 例 |
|---|---|---|
| id | 管理用ID(何でもよい、重複しなければOK) | Z-001 |
| category | ジャンル。買取表と同じ | pokemon |
| name | 商品名 | PSA10 リザードン(初期エラー版) |
| condition | 状態 | 鑑定品・美品 |
| price | 販売価格 | ¥980,000 |
| image_url | 商品写真のURL。空欄でも可 | (空欄でOK) |
| status | 在庫状況の表示 | 在庫あり / 残り1点 など |
| description | 商品説明(1〜2行) | 初期版の印刷エラー個体です。 |

### 買取実績タブ(jisseki.csv)

買取金額は掲載しない方針のため、price列はありません。

| 列名 | 内容 | 例 |
|---|---|---|
| date | 買取日の表示文言 | 2026.08.05 |
| category | ジャンル。他タブと同じ | pokemon |
| item_name | 商品名 | PSA10 リザードン(初期エラー版) |
| image_url | 商品写真のURL。空欄でも可 | (空欄でOK) |
| comment | 一言コメント。空欄でも可 | 状態良好で高額査定になりました |

URLを設定すると、サイトの買取表・在庫・買取実績ページに自動で反映されます(ページの再デプロイは不要、ブラウザで開くたびに最新のシート内容を読み込みます)。

## LINE公式アカウントのURLを設定する

宅配買取ページと、ヘッダーの「お問い合わせ」は、LINE公式アカウントの友だち追加URLにリンクしています。

1. LINE公式アカウントの管理画面から「友だち追加URL」を確認する(`https://lin.ee/xxxxxxx` の形式)
2. `src/data/site-config.js` を開き、`LINE_URL` の値を実際のURLに書き換える

## image_url に写真を入れる方法

**注意: セルに直接「画像を挿入」する機能(挿入 → 画像 → セル内に挿入)は使えません。** それだとサイト側では読み込めないので、必ず「画像のURL(文字列)」を`image_url`列に入力してください。

### おすすめ: imgur(アカウント登録不要)

1. [imgur.com](https://imgur.com/upload) を開く
2. 商品写真をアップロードする
3. アップロードされた画像を右クリック →「画像アドレスをコピー」(Copy image address)を選ぶ
   - `https://i.imgur.com/xxxxxxx.jpg` のようなURLがコピーされる
4. そのURLを`image_url`列に貼り付ける

### 代替: Googleドライブ

すでに写真をGoogleドライブで管理している場合はこちらでも可能ですが、手順がやや複雑です。

1. 写真をGoogleドライブにアップロード
2. ファイルを右クリック →「共有」→ アクセス権を「リンクを知っている全員」に変更
3. 共有リンクからファイルID(`.../d/` と `/view` の間の文字列)をコピー
4. `https://drive.google.com/uc?export=view&id=ここにファイルID` の形にして`image_url`列に入力

Googleドライブ経由は将来的にGoogle側の仕様変更で表示できなくなることがあるため、迷ったらimgurをおすすめします。

### 写真がまだない場合

`image_url`は空欄のままでOKです。サイト側は自動的に「PHOTO」というプレースホルダー表示になります。
